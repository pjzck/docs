# Bases 示例

这里放的是 Obsidian Bases 的示例 `.base` 文件，用于演示不同的表格视图配置。

| 文件 | 作用 |
|------|------|
| `全库文档.base` | 全库 Markdown 文档清单 |
| `知识库总览.base` | 只看 `knowledge/` 下的文档，按目录分组 |
| `问题排查台账.base` | 只看 `troubleshooting/` 下的记录 |
| `最近更新.base` | 只看最近 30 天修改过的文档 |
| `规划与设计.base` | 同时看 `design/` 和 `routemap/`，按目录分组 |
| `效果演示.base` | 同一个数据源，演示表格 / 卡片 / 列表三种视图 |

打开 Obsidian 后，直接点击这些 `.base` 文件即可看到对应的表格。
